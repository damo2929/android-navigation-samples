# Issue 578578614: reproduction in navigation-sample

Branch `issue-578578614` of this fork of [googlemaps-samples/android-navigation-samples](https://github.com/googlemaps-samples/android-navigation-samples), based on `main` at `a73bfba` (Navigation SDK 8.0.0). It reproduces the three problems in [issue 578578614](https://issuetracker.google.com/issues/578578614):

1. There is no supported way to set or cap the zoom while the camera follows the device. The follow zoom in free drive is 18.
2. At that zoom, `MAP_TYPE_NORMAL` draws no traffic.
3. `TOP_DOWN_HEADING_UP` stays north-up when there is no route.

The results in the tables are what we saw with `NavigationViewForAuto` on the Android Auto Desktop Head Unit (car API 8, Android Auto 18.0); this branch makes the same calls on the sample's phone `NavigationView`. It builds against SDK 8.0.0; we have not yet run it in the sample with a key.

The only code change is in `NavViewActivity.kt`: `startZoomRepro(map)`, called from the existing `withMapAsync { … }` block. It turns traffic on, sets the road map, logs the camera once a second under the tag `b578578614`, and runs one step every 15 s. See the diff against `main`.

## Set-up

1. Add your key to `navigation-sample/local.properties`: `MAPS_API_KEY=<key with the Navigation SDK enabled>`.
2. Use an Android emulator (we used the API 36 Google Play image) and build and install the debug build: `cd navigation-sample && ./gradlew installDebug`.
3. Grant location on the splash screen, open **NavViewActivity** and accept the Navigation terms. **Do not set a destination**: parts 1 and 2 are free drive, with no route.
4. Give the device a moving location on roads with live traffic. For example, use emulator **Extended controls → Location → Routes**: plan a route through a town at a busy time and press **Play route**. Or send `adb emu geo fix <lon> <lat>` positions along a road once a second.
5. Watch `adb logcat -s b578578614` and the map.

## Parts 1 and 2: follow zoom and traffic

The steps start 15 s after the map is ready, one every 15 s. Take a screenshot a few seconds into each.

| Step | Call | Zoom in the log | Traffic on the road map |
|---|---|---|---|
| A | `followMyLocation(TILTED)` | 18.00, following | none |
| B | `setMinZoomPreference(17f)`, `setMaxZoomPreference(17f)`, then follow | still 18.00 | none |
| C | `resetMinMaxZoomPreference()`, `animateCamera(zoomTo(17f))` | 17, `following=false` | shown at 17 |
| D | `followMyLocation(TILTED)` again | back to 18.00 | none |
| E | `moveCamera(zoomTo(16f))`, then follow | back to 18.00 within 1 s | none |
| F | deprecated `followMyLocation(TILTED, FollowMyLocationOptions.builder().setZoomLevel(17f).build())` | **17.00, following** | **shown** |
| G | `followMyLocation(TILTED)` without options | back to 18.00 | none |
| H | `MAP_TYPE_HYBRID` | 18.00 | shown (hybrid draws it at 18) |

Only the deprecated `FollowMyLocationOptions` (step F) holds a zoom while following, and only at 17 does the road map draw traffic.

## Part 3: heading-up without a route

No code change needed. With the location moving and no destination:

1. Pick **Camera Mode Options → Following: Heading up**. The map stays north-up (camera bearing 0) while only the chevron turns.
2. Pick **Following: Tilted**. The map turns to the heading.
3. Set a destination so guidance starts, then pick **Following: Heading up** again. The map now turns to the heading. After guidance stops it is north-up again.

## Expected

1. A supported (not deprecated) way to set or cap the zoom while following, as `FollowMyLocationOptions.setZoomLevel` did.
2. Traffic drawn on `MAP_TYPE_NORMAL` at the zoom the SDK itself follows at in free drive, or a free-drive follow zoom at which it is drawn.
3. `TOP_DOWN_HEADING_UP` turning with the heading without a route, as `TILTED` does.
